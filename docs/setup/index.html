Step 2 — What do you want to publish?

This determines which services you need to set up. You can add channels later.

✍️ Blog posts
Long-form content published to your public blog — no extra service needed, always enabled.
📢 Social media
Post threads, articles, and updates to Twitter/X, LinkedIn, Threads, Instagram and more via Zernio.
📧 Email newsletter
Send newsletter issues to your subscriber list via Resend. Subscribers managed in Resend audiences.

Step 3 — Your domain

The web address where your app will live. You can always add a custom domain later.

Important: GitHub OAuth is tied to this URL. Set it correctly from the start — changing it later requires re-creating your GitHub OAuth App.
Your SITE_URL will be: https://social-pipeline.workers.dev

Step 4 — Cloudflare account

Cloudflare hosts your app at the edge in 300+ cities. Also provides session storage (KV), file storage (R2), and AI request routing (AI Gateway).

Workers
100k req/day free — pricing ↗
KV + R2
100k reads/day + 10 GB storage free
AI Gateway
Free (it's a proxy, no per-call cost)
Required for
Everything — app host, sessions, storage, AI routing
AI spend caution: Your AI Gateway routes prompts to OpenRouter. Set a spending limit to avoid surprise bills: AI Gateway rate limiting ↗
  1. Create a free Cloudflare account at cloudflare.com (skip if you have one).
  2. Go to My Profile → API Tokens → Create Token → Create Custom Token.
  3. Add these permissions: Workers Scripts: Edit, Workers KV Storage: Edit, Workers R2 Storage: Edit, AI Gateway: Edit, Account Settings: Read.
  4. Copy the token (shown once) and paste it below.
Find it in the Cloudflare dashboard right sidebar on any zone page.

Step 5 — Convex account

Convex is your database and serverless backend. All your content, pipeline state, workspaces, and settings live here.

Free tier
1M calls/mo, 1 GB storage — pricing ↗
Required for
Database, auth, pipeline, all backend logic
  1. Create an account at convex.dev ↗.
  2. Create a new project — give it any name (e.g. social-pipeline).
  3. Go to Settings → Deploy Key and create a deploy key. Copy it.
  4. Copy the Deployment URL from the dashboard (e.g. https://happy-animal-123.convex.cloud).

Step 6 — GitHub OAuth App

This lets users sign in with their GitHub account. Takes about 2 minutes to create.

Cost
Free — part of your GitHub account
Required for
User authentication / sign-in
  1. Go to GitHub → Settings → Developer Settings → OAuth Apps → New OAuth App.
  2. Fill in 4 fields:
    Application name: social-pipeline
    Homepage URL: https://your-domain.com
    Authorization callback URL: https://your-convex.convex.site/api/auth/callback/github
  3. Click Register application — copy the Client ID.
  4. Click Generate a new client secret — copy it immediately (shown once).
Open GitHub OAuth Apps ↗

Step 7 — OpenRouter (AI models)

Routes your content pipeline prompts to 200+ AI models. Required for the research, outline, and draft stages.

Cost
Pay-per-use — model prices ↗
Typical run
$0.01–$0.10 per full article
Usage-based billing: Charged per token. Purchase a credit top-up (e.g. $10) to start. Monitor spend at openrouter.ai/activity ↗. Also set a spend limit in your Cloudflare AI Gateway (done in Step 4).
  1. Create an account at openrouter.ai.
  2. Add credits: Account → Credits → Buy (start with $5–$10).
  3. Create an API key: Account → Keys → Create Key.
Without this, AI generation steps won't work. You can add it later.

Free tier

Step 9 — Resend (email newsletters)

Sends your newsletter issues to subscribers. Also manages your audience/contact list — there is no separate subscriber table in the app; Resend owns that data.

Free tier
3,000 emails/mo, 100/day — pricing ↗
Required for
Newsletter sending + subscriber management
  1. Create an account at resend.com.
  2. Verify your sending domain under Domains.
  3. Create an Audience — this is where your subscribers will be stored. Copy the Audience ID.
  4. Go to API Keys → Create API Key and copy it.

Step 9 — Zernio (social publishing)

Publishes your content to Twitter/X, LinkedIn, Threads, Instagram, and 10+ other platforms from a single API call.

Free tier

Required for
Social media publishing
  1. Create an account at zernio.com ↗.
  2. Connect your social media profiles (Twitter/X, LinkedIn, etc.).
  3. Go to Settings → API → Create Key and copy it.
